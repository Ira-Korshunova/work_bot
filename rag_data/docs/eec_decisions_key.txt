# Ключевые решения Евразийской экономической комиссии (ЕЭК)
# ЕЭК — наднациональный регулирующий орган ЕАЭС (ст. 8 Договора о ЕАЭС).
# Структурированный конспект (не верстка официальных актов). Источник: eaeunion.org.

Раздел I. Органы управления ЕАЭС

Статья 8. Структура органов ЕАЭС
Органы Евразийского экономического союза: Высший Евразийский экономический совет
(на уровне глав государств); Евразийский экономический совет (на уровне глав
правительств); Евразийская экономическая комиссия (ЕЭК) — наднациональный
постоянно действующий регулирующий орган; Суд ЕАЭС.
Решения ЕЭК обязательны для государств-членов и хозяйствующих субъектов.

Глава 2. Решения ЕЭК по таможенно-тарифному регулированию

Решение ЕЭК № 48. Единый таможенно-тарифный регулирование ЕАЭС
Утверждён Единый таможенный тариф (ЕТТ) ЕАЭС — система ставок ввозных таможенных пошлин,
применяемых единообразно к товарам, ввозимым на таможенную территорию ЕАЭС из третьих
стран. Ставки дифференцированы по кодам ТН ВЭД ЕАЭС. Изменения ставок принимаются ЕЭК
на основе предложений государств-членов.

Решение ЕЭК № 54. Меры нетарифного регулирования
Утвержден единый перечень товаров, к которым применяются запреты и ограничения во
внешней торговле с третьими странами (квоты, лицензирование, регистрация, запрет).
Порядок выдачи лицензий/разрешений определён для государств-членов.

Решение ЕЭК № 107. Методы определения таможенной стоимости
Закреплены 6 методов определения таможенной стоимости (по стоимости сделки,
идентичные/однородные товары, вычитание, сложение, резервный) — соответствуют
ТК ЕАЭС и Соглашению ВТО по оценке таможенной стоимости.

Глава 3. Решения ЕЭК по ТН ВЭД и происхождению

Решение ЕЭК № 57. ТН ВЭД ЕАЭС
Утверждена Товарная номенклатура внешнеэкономической деятельности ЕАЭС (на базе
Гармонизированной системы описания и кодирования товаров ВТО). Код ТН ВЭД ЕАЭС —
10 знаков (первые 6 — Гармонизированная система, 7–8 — Кукузная, 9–10 — национальные
детализации ЕАЭС). Изменения в номенклатуру вносятся решениями ЕЭК.

Решение ЕЭК № 49. Правила определения страны происхождения
Определён порядок определения страны происхождения товаров для применения
преференциальных режимов (СНГ, развивающиеся страны). Критерии: товар полностью
произведён в стране либо подвергся достаточной переработке (правило «изменения
товарной позиции», процентная доля добавленной стоимости, конкретные операции).
Подтверждается сертификатом происхождения (СТ-1, форма А).

Глава 4. Решения ЕЭК по общему рынку

Решение ЕЭК № 42. Сертификация и маркировка
Определён порядок применения единых санитарных, ветеринарно-санитарных и
карантинных мер; маркировка «ЕАС» для товаров, подлежащих тех.регулированию ЕАЭС
(соответствие тех.регламентам ЕАЭС).

Решение ЕЭК № 30. Единый реестр уполномоченных экономических операторов
УЭО (уполномоченный экономический оператор) — статус, предоставляющий упрощения:
ускоренный выпуск (4 часа), отдельные коридоры, отсрочка уплаты платежей. Единый
реестр УЭО ведёт ЕЭК; статус, полученный в одном государстве, признаётся во всём ЕАЭС.

Глава 5. Решения ЕЭК по электронному декларированию

Решение ЕЭК № 157. Электронное декларирование и обмен сведениями
Утверждены форматы электронных таможенных документов, порядок обмена сведениями
между таможенными органами государств-членов, единая система управления рисками
в таможенном контроле. Цель — безбумажное декларирование и взаимное признание
таможенного контроля.

экономической комиссии (eaeunion.org) в разделе «Нормативная база». Решения ЕЭК
имеют приоритет над национальным таможенным законодательством при расхождении.

уровне — ЕЭК (Евразийская экономическая комиссия).
